Series widget (RFC 0001 slice 2): `baseRegistry.widgets.series` draws the engine's grouped values as a compact, captioned two-column table — group label and preformatted text per row, `measureLabel` as the value header, skeleton rows while loading, "Nothing to show yet" when loaded empty, and notes for skipped records and a partial read. Every word is a `strings` prop. `display: "bar"` and `"line"` draw the same table until the chart cards land. `@yadad/core` `^0.13.0` joins the peer range. Import from `@yadad/components/series`; styles from `@yadad/components/styles/series.css`.
